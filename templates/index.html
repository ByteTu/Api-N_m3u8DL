API 接口文档

新建下载任务

POST /download

请求参数:

参数必选类型说明
must是stringm3u8 视频 URL 地址
save-dir是string保存视频目录 在项目/data/videos/创建目录
save-name是string保存视频名称
base-url否string设置 BaseURL
max-speed否string限速，支持如：15M、100K
binary-merge否bool二进制合并，默认 False
del-after-done否bool完成后删除临时文件，默认 True

返回参数:

参数类型说明
codeint状态码，0=成功，1=失败
msgstring提示信息
consolestring执行的命令
taskIdstring任务 ID
pidint进程 PID

请求示例:

POST http://127.0.0.1:5050/download

{
  "must": "https://example.com/video.m3u8",
  "save-name": "视频文件名称",
  "save-dir": "download"
}

返回示例:

{
  "code": 0,
  "msg": "任务已在后台启动，日志面板实时显示下载进度",
  "console": "./N_m3u8DL-RE.exe https://example.com/video.m3u8 --tmp-dir ./data/temp_dir/ --save-dir ./data/download/download --save-name 视频文件名称 --log-file-path ./Logs/视频文件名称_20241201_120000.log",
  "taskId": "T000001",
  "pid": 12345
}
